## 🎯 О ПРОЕКТЕ

**PatriotOS** — полноценный концепт-прототип российской операционной системы, демонстрирующий возможности отечественного ПО. Проект представляет собой веб-эмулятор рабочего стола с оконной системой, восемью предустановленными приложениями, поддержкой двух языков и полной локализацией интерфейса.

> *«Самая главная операционная система в России начинается с одной HTML-страницы. Версия 1.0 — это только начало.»*

---

## ✨ ВОЗМОЖНОСТИ

### 🖥️ Интерфейс
- Экран блокировки с анимированным входом
- Рабочий стол со сменяемыми обоями (флаг, герб, кремль, просторы, берёза)
- Кнопка **«Пуск»** с меню всех приложений
- Вертикальный док с иконками
- Панель даты/времени с индикатором праздников
- Полноценная оконная система с управлением (свернуть/развернуть/закрыть)
- Перетаскивание окон (только для ПК)
- Адаптивный дизайн для всех устройств

### 📦 Приложения

| Приложение | Описание |
|------------|----------|
| **Калькулятор** | Математические вычисления |
| **Браузер** | Просмотр веб-страниц (только .ru, .рф) |
| **Магазин приложений** | Магазин приложений |
| **Румузыка** | Музыкальный плеер с плейлистами |
| **Рувидео** | Видеоплеер с YouTube-подобным интерфейсом |
| **Файлы** | Файловый менеджер с виртуальной ФС |
| **Настройки** | Параметры системы |
| **Календарь** | Производственный календарь РФ |
| **Ручат** | Патриот мессенджер |

### 🗣️ Диктор
- Три режима: при наведении, при клике, при выделении
- Поддержка русского и белорусского языков
- Озвучивание текста интерфейса

### 🌐 Локализация
- Полный перевод интерфейса на русский и белорусский языки
- Названия праздников на обоих языках
- Мгновенное переключение с перезагрузкой страницы

### 🔒 Безопасность и данные
- Все данные хранятся локально (localStorage)
- Валидация вводимых данных
- Ограничение на российские домены
- Сохранение настроек, файлов и установленных приложений
